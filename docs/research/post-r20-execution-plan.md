## Quality gates and selection rules

Preserve existing protocol: compare each of six directions separately to matching full128 baseline, chrF++ drop at most1 absolute point, no increased empty/truncated/digit-mismatch counts under the existing evaluator and identity constraints. Chinese↔Burmese primary pair cannot be averaged away. Secondary directions cannot be silently excluded or have relaxed thresholds. Compare identical held-out validation IDs and prompts, same runtime/precision, actual stop reasons and actual generated tokens when needed. Reuse baseline outputs only if compatible; unknown stop/token evidence is explicitly not assessed and cannot qualify. The old R19 canonical masked/physical mechanism HOLD remains a separate prerequisite; a practical GGUF quality comparison does not by itself resolve that gate. R20 author may have newer evidence; R21 reads it before further decisions.

R22 first witness: use fixed existing six-direction witness set for a quick paired smoke, prioritize zh-my/my-zh analysis, then 120 validation rows under matched server execution if useful; small witness is not a release gate. No new test split scoring, no fitting expert IDs to validation outputs. Preserve raw generated text, true termination, token identities, request-linked server timings, exact commands and measured resource metrics. Do not manufacture missing evidence, do not label client RSS as model RSS. Avoid repeated full runs when valid frozen records suffice. Baseline and candidate comparisons must distinguish prompt cache, server vs direct execution, and precision.

R23 output-sensitive study design: use disjoint calibration-only subsets with all six directions and prefill/decode strata, fixed IDs/sample budget before run. Existing engine.py expert_combine computes per-token expert outputs before weighting; observer may retain bounded summaries of w_e*f_e(x), energy, top-k alternatives, normalized mixture error rather than all activations. Test baseline observer equivalence on synthetic fixture and a finite real witness; distinguish proxy and actual end-to-end quality. Use local layer output error normalized by full routed output norm and quantify shared contribution, avoid assuming weight magnitude == functional importance. Compare original96/P12 against new method using calibration holdout; only candidate selection on calibration. No claims of semantic specialization from route stats alone. R23 is the fallback if P12 fails or a planned next reduction benefits; do not spend GPU validating many minor proxy variants.
